Reservoir Simulator

Build a run configuration, read the deck it produces, and inspect a finished run. The simulator is CUDA and runs on a GPU; this page prepares its input and reads its output.

Run configuration

Every control here maps to one deck keyword.

TENSORCORE forms the local connection Jacobians as one batched GEMM. TF32 needs compute capability 8.0 or newer; below that the same path runs in FP32 on CUDA cores.
